# SafeRoute AI — Project Guidelines

Refer to [.agents/rules/project_rules.md](file:///.agents/rules/project_rules.md) for full details.

### Core Principles:
1. **Beginner-Friendly B.Tech Viva Code:** Simple functions, loops, dictionaries. No complex classes, design patterns, or over-engineering.
2. **Real Core AI Algorithms:** Genuine scikit-learn Decision Tree, handcrafted pure Python A* algorithm, goal-based agent, and transparent IF-THEN rules. No fake algorithm mockups.
3. **Data Integrity:** Clearly label all data as synthetic academic demonstration data. No false claims of real crime records.
4. **Step-by-Step Execution:** Inspect existing code -> Identify minimum changes -> Explain files -> Implement only requested stage -> Test -> Explain in simple language.
